# GPay-System

 This is a simple GPay System where the user can transfer money to different users. It is integrated with simple rules and an ML model in the backend to detect fraud. The data for this project is divided into 2:-transactions.csv files - hold the transactional data of the users, everytime the users transfer money from one another. users.csv files- hold the user information along with their password and balances.
